# 📊 Retail Sales Data Analysis (SQL Project)

## 📌 Project Overview
This project focuses on analyzing retail sales performance and understanding customer purchasing behavior. Using structured SQL queries, I managed a relational database containing customer details and transactions to extract actionable business insights.

## 🛠️ Tech Stack & Concepts Used
* *Database Platform:* PostgreSQL / MySQL
* *SQL Concepts:* DDL (Table Creation), DML (Data Insertion), Joins, Aggregate Functions (SUM, COUNT), Grouping (GROUP BY, HAVING), and Ordering.

## 🏗️ Database Schema & Structure

### 1. Customers Table (customers_data)
Stores demographic attributes of retail shoppers.
* customer_id (Primary Key)
* customer_name, age, gender, location

### 2. Sales Table (sales_data)
Tracks all individual transaction details.
* order_id (Primary Key), customer_id (Foreign Key link)
* order_date, product_category, quantity_ordered, price_per_unit, total_amount

## 🔍 Business Questions Solved & Key Insights

### 📈 1. Total Revenue Generated by Each Product Category
*Business Objective:* Identify which product categories drive the highest sales revenue to optimize inventory.
sql
SELECT 
    product_category, 
    SUM(total_amount) AS total_revenue,
    SUM(quantity_ordered) AS total_items_sold
FROM sales_data
GROUP BY product_category
ORDER BY total_revenue DESC;

*Expected Output:*

| product_category | total_revenue | total_items_sold |
| :--- | :--- | :--- |
| Electronics | 39800.00 | 4 |
| Home Decor | 9000.00 | 3 |
| Clothing | 8600.00 | 8 |

---

### 💎 2. Identifying High-Value Customers (HVCs)
*Business Objective:* Segment top-spending customers who have spent more than ₹5,000 for loyalty rewards.
sql
SELECT 
    c.customer_name, 
    c.location, 
    SUM(s.total_amount) AS total_spent
FROM customers_data c
JOIN sales_data s ON c.customer_id = s.customer_id
GROUP BY c.customer_name, c.location
HAVING SUM(s.total_amount) > 5000
ORDER BY total_spent DESC;

*Expected Output:*

| customer_name | location | total_spent |
| :--- | :--- | :--- |
| Amit Verma | Bangalore | 29000.00 |
| Aarav Sharma | Mumbai | 19000.00 |

---

### 👥 3. Sales Distribution by Gender Demographics
*Business Objective:* Analyze buying patterns across genders to target marketing campaigns effectively.
sql
SELECT 
    c.gender, 
    COUNT(s.order_id) AS total_orders,
    SUM(s.total_amount) AS total_sales
FROM customers_data c
JOIN sales_data s ON c.customer_id = s.customer_id
GROUP BY c.gender;

*Expected Output:*

| gender | total_orders | total_sales |
| :--- | :--- | :--- |
| Male | 5 | 53000.00 |
| Female | 2 | 4400.00 |

---

## 💡 Key Business Takeaways
1. *Top Performer:* The *Electronics* segment dominates the revenue share, making it the primary target for upsell campaigns.
2. *Target Audience:* *Male customers* contributed significantly higher total sales revenue in this specific sample dataset.
3. *Geographic Stars:* High-value customers are heavily concentrated in major tier-1 cities like *Bangalore* and *Mumbai*.
